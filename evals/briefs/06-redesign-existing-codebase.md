# Redesign the Brightwater Library events page

Brightwater is a fictional public library. The current site is already in this project:
`index.html` and `styles.css`.

## Who it is for

Library patrons of all ages looking for upcoming events, many on older phones, some using
screen magnification.

## What to do

Redesign the existing events page in place. Keep it plain HTML and CSS (no framework). Keep
all existing content and links; improve hierarchy, readability, spacing, and how easily the
event list can be scanned. Keep the existing brand teal (`#1d6f73`) and the library's name
as the logo text.

## Problems reported by staff

- The event list is a wall of text; dates are hard to find.
- The filter buttons are tiny on phones.
- Some text is low contrast; the footer is hard to read.
- The page scrolls sideways on small phones.

## Constraints

- Change the existing files; do not start a separate site.
- Works from 320px to 1440px, at 200% zoom, and with a keyboard only.
- Do not add events, dates, or facts that are not already in the page.
