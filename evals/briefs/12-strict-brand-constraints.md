# Membership page for Halden Rowing Club, under strict brand rules

Halden Rowing Club is fictional. Its brand rules below are mandatory, not suggestions.

## Who it is for

Adults considering joining a community rowing club, including complete beginners.

## What to build

A static page, `index.html` with CSS, no build step.

## Brand rules (mandatory)

- Colours: only these four. Navy `#14213d` (primary text and dark surfaces), Oar Yellow
  `#fca311` (accents only, never body text on white), White `#ffffff`, Mist `#e5e5e5`.
- Type: a system serif stack (`Georgia, "Times New Roman", serif`) for headings and a system
  sans-serif stack for body text. No web fonts.
- Corners are square (no border radius). No shadows. No gradients.
- Logo: the words "HALDEN RC" in the heading serif, uppercase, letter-spaced 0.1em.
- Tone: plain and welcoming; no exclamation marks.

## Content

- Hero: "Learn to row on the Halden this spring." Button: "Book a taster session".
- Membership options: Taster (one session, £15), Learn to Row course (six weeks, £120),
  Full membership (£45 per month), each with three included items.
- Session times: Saturday 08:00 and 10:00, Wednesday 18:30.
- What to bring, and the safety note "You must be able to swim 50 metres."
- Contact form: name, email, message.

## Constraints

- Every text and background pair meets WCAG AA using only the four brand colours.
- Works from 320px to 1440px; fully keyboard accessible.
