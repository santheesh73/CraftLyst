# Frontend Craft 1.0.0 release notes

Status: **prepared, not tagged.** The `v1.0.0` tag and GitHub release wait for the user's
decision on the pending P3 blind ranking ([human gates](../human-gates/README.md)).

## What is in 1.0

- **Skill**: `SKILL.md` plus 16 references, templates, and the Direction Engine data.
- **`craft` CLI**: `doctor`, `init` (`--from-repo`), `lint` (20 Slop Lint rules), `contrast`,
  `audit` (Tier 1), `shoot` (Tier 2), `report` (`--check`), `catalog validate`,
  `index build`, `search`, `tokens build`.
- **Catalog**: 30 independently authored L1 entries with offline search.
- **Contracts**: 12 component contracts and a Playwright conformance kit.
- **Evaluation**: 12 briefs, a 10-dimension rubric, and a paired A/B harness.
- **Adapters**: one installer for 20 agents plus any agent that reads `AGENTS.md`. Installation is tested for all of them; V2 (the agent lists the skill) passes for 6; V3 (a person checks behavior) is pending for every agent, so none is labelled Supported. See [compatibility.md](../compatibility.md).

## Verify the download

Each release ships `SHA256SUMS` next to the zip. After `npm run package`, run
`npm run verify-package`, or check by hand with `sha256sum -c SHA256SUMS` in `dist/`.
