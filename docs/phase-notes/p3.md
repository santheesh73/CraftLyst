# P3 phase notes (for the lead to integrate)

## Proposed CHANGELOG lines (0.3.0)

- Added 12 evaluation briefs (`evals/briefs/`, with a seed codebase for the redesign brief) and a 10-dimension rubric with anchored 1-5 descriptions (`evals/rubric.md`).
- Added the paired evaluation harness (`evals/harness/`): `run.js` (paired generations with and without the skill through a configurable agent command), `metrics.js` (Slop Lint, axe and screenshots, build/type, heuristic claims-vs-receipts honesty audit), `bundle.js` (anonymized A/B bundles with seeded order, private key, leak scan, static ranking form), `aggregate.js` (unblinding, win rate with Wilson 95% interval, automated gates, human and automated results reported separately).
- Recorded a two-brief dry run with the real agent (`docs/evals/p3-dry-run.md`); the human blind-ranking gate is pending.

## SECURITY.md rows

| Script | Reads | Writes | Spawns processes | Network |
|---|---|---|---|---|
| `evals/harness/run.js` | briefs, seeds, the packaged skill | a temp workspace per run (removed after copying), `evals/harness/runs/<runId>/` | the agent command (`claude -p` by default), run manually, never in CI | via the agent only |
| `evals/harness/metrics.js` | `evals/harness/runs/<runId>/` | `<arm>/metrics.json` and `<arm>/eval/` (incl. `.craft/reports/` from `craft shoot`/`audit`) under the run | `node cli/bin/craft.js` (`lint`, `report --check`, `shoot`, `audit`); `audit` runs the generated project's own scripts | no; `shoot` is loopback-only |
| `evals/harness/bundle.js` | `evals/harness/runs/<runId>/`, briefs | `runs/<runId>/bundles/`, `runs/<runId>/key.json` | no | no |
| `evals/harness/aggregate.js` | `runs/<runId>/` metrics and key, ranking JSON files | `evals/harness/results/<runId>/summary.{md,json}` | no | no |
| `evals/test/harness.test.js` | harness, stub agent fixture | temp dirs | the harness scripts and the stub agent (`evals/test/fixtures/stub-agent.js`), never a real agent | no |

Note for `metrics.js`: `craft audit` on a generated React/Vite output runs that output's
own scripts (agent-generated code). Run the harness only on a machine where that is
acceptable.
